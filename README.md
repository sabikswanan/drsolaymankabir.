# Dr. Md. Solayman Kabir — Portfolio

Personal portfolio website of **Dr. Md. Solayman Kabir** (ড. মো. সোলায়মান কবীর),
Associate Professor & Head, Department of Bangla, Rajuk Uttara Model College, Dhaka.

🔗 Live: https://drsolaymankabir.vercel.app

## Features
- Bangla letter-rain hero with touch/mouse interaction
- Animated journey timeline (1984 – present)
- Interactive bookshelf of his publications
- Recitation player and a command console (English + Bangla)
- Downloadable CV
- No external requests — fast on mobile data, works on iPhone & desktop

## Tech
Plain HTML, CSS and JavaScript. Hosted on Vercel.

Built by [Sabik Swanan](https://github.com/sabikswanan).
