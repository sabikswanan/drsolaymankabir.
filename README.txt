Dr. Md. Solayman Kabir — portfolio site

Deploy: import this folder into Vercel (Framework: Other, no build command), or run `npx vercel --prod` here.

Recitation sound:
  The play button uses the device's Bangla voice by default.
  To use his real recitation instead, record the two lines
  ("বল বীর— বল উন্নত মম শির!") and save the file as
      assets/recitation.mp3
  The site will play that recording automatically.
